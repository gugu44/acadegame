# acadegame

플로터(Flutter)와 Flame으로 구현한 레트로 갤러그 스타일 슈팅 게임입니다. 예전 오락실 느낌의 별빛 배경, 적 편대, 탄막을 그대로 옮겨와 간단한 조작으로 즐길 수 있습니다.

## 특징
- 별빛 배경과 삼각형 비행기 실루엣으로 표현한 클래식 아트 스타일
- 좌우 이동 + 단발 샷으로 즐기는 직관적인 조작
- 점수·라이프 HUD와 웨이브 단위 적 편대 스폰
- 적/아군 탄환 충돌, 폭발 이펙트, 게임 오버 오버레이 제공

## 실행 방법
> 로컬에 Flutter SDK가 설치되어 있어야 합니다.

```bash
flutter pub get
flutter run -d chrome   # 웹으로 실행 (키보드/마우스 지원)
# 또는 연결된 에뮬레이터/디바이스에서 실행
```

### 조작법
- **이동**: 화살표 좌/우 키 또는 A/D
- **공격**: 스페이스바 / 화면 탭
- 라이프가 모두 소진되면 "INSERT COIN" 버튼으로 재시작할 수 있습니다.
